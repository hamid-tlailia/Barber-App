# مِقص — نظام إدارة الصالونات (رجالي · نسائي · مختلط)

تطبيق عربي لإدارة الصالونات. يعمل على الويب وأندرويد (APK أصلي عبر Capacitor)، ويحفظ البيانات في السحابة مع مزامنة فورية بين الأجهزة. يواصل العمل عند انقطاع الإنترنت، وتُرفع التغييرات تلقائياً عند عودة الاتصال.

## الميزات

| القسم | ما يقدمه |
|---|---|
| **المواعيد** | حجز في ٤ خطوات بسيطة، وعدة خدمات في موعد واحد، وموظف لكل خدمة، و«وقت انتظار» (مثل تثبيت الصبغة) يحرّر الموظفة لعميلة أخرى، وخدمة منزلية، وعربون، ومنع التعارض، وحالات: وصل / لم يحضر |
| **العملاء** | ملف كامل يشمل الحساسية وتركيبة الصبغة وعيد الميلاد وVIP وصور قبل/بعد (بموافقة)، ونقاط ولاء، ونمط الزيارات، واستيراد من Excel/CSV أو نص منسوخ |
| **الدفع** | دفع جزئي ومقسّم، وخصم، وإكرامية للموظف، وباقات جلسات، وبطاقات هدايا، وبيع منتجات، ومصروفات، وإغلاق الصندوق اليومي، وفاتورة تُرسل بواتساب |
| **الرسائل الذكية** | تذكير المواعيد، واسترجاع العملاء المنقطعين (حسب نمط كل عميل)، وتهنئة أعياد الميلاد، وقائمة انتظار تقترح نفسها عند أي إلغاء |
| **الذكاء** | كشف خطر الغياب واقتراح عربون، وتوقع نفاد المخزون مع قائمة طلب جاهزة للمورّد، والعمولات، وإشغال الفريق، وتقرير يومي، و**عدّاد «قيمة حققها التطبيق»** |
| **واتساب للأعمال** (اختياري) | تذكير تلقائي يرد عليه العميل بـ 1 أو 2 فيتحدّث الجدول، ومساعد ذكي (Claude) يحجز بالعربي على مدار الساعة، وتقرير ليلي لصاحب المحل |
| **الحجز الأونلاين** | رابط عام يوضع في انستغرام وخرائط جوجل، ويصل الحجز فوراً لكل الأجهزة |
| **الفريق والصلاحيات** | مالك / مدير / استقبال / موظف. الموظف يرى مواعيده فقط دون أرقام أو إيرادات، والحذف للمالك والمدير فقط |
| **سجل التعديلات** | من عدّل أو حذف أو ألغى دفعة ومتى (يُسجَّل على الخادم ولا يمكن التلاعب به) |
| **الفروع** | أكثر من صالون لنفس الحساب مع تبديل سريع |
| **الترخيص** | تجربة مجانية ٧ أيام، بعدها يُقفل التطبيق تلقائياً (يفرضه الخادم وليس الجهاز فقط)، مع بقاء تصدير البيانات متاحاً. التفعيل من «لوحة المطوّر» داخل التطبيق |

## التشغيل محلياً

```bash
npm install
cp .env.example .env    # بدون .env يعمل التطبيق في «وضع الجهاز الواحد» للتجربة
npm run dev
npm test                # اختبارات منطق المواعيد والدفع والذكاء والمزامنة
```

## إعداد قاعدة البيانات (Supabase)

1. أنشئ مشروعاً على [supabase.com](https://supabase.com) (المنطقة الأقرب: Frankfurt أو Mumbai).
2. من **SQL Editor** نفّذ محتوى `supabase/migrations/0001_init.sql`.
3. من **Authentication ← Providers** فعّل Email، ومن **URL Configuration** أضف رابط موقعك.
4. ضع `VITE_SUPABASE_URL` و`VITE_SUPABASE_ANON_KEY` في `.env`.
5. سجّل حسابك في التطبيق، ثم اجعله مطوّراً (لوحة تفعيل الاشتراكات):
   ```sql
   insert into app_admins (user_id) select id from auth.users where email = 'بريدك@example.com';
   ```

### الترخيص والبيع
- كل صالون جديد يحصل على تجربة ٧ أيام تلقائياً. التجربة **لا تتكرر** لنفس الحساب أو لنفس رقم الهاتف.
- عند انتهائها يرفض الخادم أي كتابة، ويعرض التطبيق شاشة الاشتراك مع زر واتساب للمبيعات.
- بعد الدفع افتح **لوحة المطوّر** (أيقونة الدرع أعلى التطبيق) واختر: شهر / سنة / مدى الحياة. يُفتح التطبيق لدى العميل خلال دقائق.
- أسعار الخطط في `src/lib/license.js`.

## واتساب الذكي (اختياري)

1. أنشئ تطبيقاً في [Meta for Developers](https://developers.facebook.com) وأضف منتج WhatsApp.
2. اعتمد قالبين من WhatsApp Manager (اللغة العربية `ar`):
   - `appointment_reminder`: «مرحباً {{1}}، تذكير بموعدك في {{2}} يوم {{3}} الساعة {{4}}. للتأكيد أرسل 1، وللإلغاء أرسل 2.»
   - `daily_report`: «تقرير {{1}} اليوم: {{2}}»
3. انشر الدوال وأضف الأسرار:
   ```bash
   supabase functions deploy whatsapp-webhook send-reminders daily-report
   supabase secrets set WA_TOKEN=... WA_PHONE_NUMBER_ID=... WA_APP_SECRET=... WA_VERIFY_TOKEN=اختر-نصاً CRON_SECRET=اختر-نصاً-طويلاً ANTHROPIC_API_KEY=...
   ```
4. في Meta اضبط Webhook على `https://PROJECT_REF.supabase.co/functions/v1/whatsapp-webhook` مع `WA_VERIFY_TOKEN`، واشترك في `messages`.
5. نفّذ `supabase/cron.sql` (بعد استبدال القيم) لتشغيل التذكير كل ساعة والتقرير كل ليلة.

المساعد الذكي يستخدم نموذج `claude-opus-5-5` افتراضياً، ويمكن تغييره عبر السر `ANTHROPIC_MODEL`. فعّلنا فيه `fallbacks: "default"`، فإذا رفض النموذج طلباً يُعاد الطلب تلقائياً على نموذج بديل.

## تطبيق أندرويد (APK)

```bash
npm run android    # يبني الويب ← يزامن Capacitor ← يبني APK
# الناتج: android/app/build/outputs/apk/debug/app-debug.apk
```

يتطلب JDK 21 وAndroid SDK. يمكن أيضاً بناؤه من GitHub: تبويب **Actions ← Android APK ← Run workflow**، ثم تنزيل الـ APK من صفحة التشغيل. ضع قيم `.env` كـ Secrets في المستودع حتى يعمل الـ APK مع قاعدة البيانات.

للنشر على Google Play تحتاج نسخة موقّعة (`assembleRelease` مع keystore) وحساب مطوّر Google Play (25$ لمرة واحدة).

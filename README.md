# مِقص — إدارة صالون الحلاقة

تطبيق ويب عربي RTL لإدارة صالون الحلاقة، بواجهة فاخرة متجاوبة تتكيف تلقائياً مع مظهر جهازك، مع إمكانية اختيار الوضع النهاري أو الليلي يدوياً.

## الميزات

- **لوحة تحكم عملية:** ملخص اليوم، المواعيد التالية، الإيرادات المسجلة، أداء الأسبوع، وتنبيهات المخزون المنخفض.
- **جدولة مرنة:** تقويم أسبوعي، بحث وتصنيف، اقتراح أول وقت متاح، منع تعارض الحجوزات، وإمكانية إسناد كل موعد إلى حلاق.
- **إدارة الزبائن:** ملفات وتفضيلات وسجل زيارات، روابط اتصال وواتساب، ورصيد ولاء محسوب تلقائياً بنقطة لكل ١٠ ر.ق من الدفعات المسجلة.
- **فريق العمل:** إضافة الحلاقين وتخصصاتهم وبياناتهم، توزيع الحجوزات، ومؤشرات إيراد وعمولة تقديرية.
- **المخزون:** كتالوج المنتجات وتكلفتها وسعر بيعها، حدود إعادة الطلب، حركات التوريد والصرف، تنبيهات الكميات المنخفضة، وتصدير CSV.
- **الدفعات والفواتير:** تسجيل وسيلة الدفع في سجل الصالون، متابعة المستحقات، وطباعة فاتورة مبسطة أو حفظها PDF من المتصفح.
- **التقارير:** الإيرادات والخدمات والفريق حسب الفترة، مع تصدير سجل المواعيد CSV.
- **الإعدادات والنسخ الاحتياطي:** اسم الصالون والتحية، الخدمات والأسعار، وضع العرض، وتنزيل/استعادة نسخة JSON.

## التشغيل

```bash
npm install
npm run dev
```

ثم افتح العنوان الذي يعرضه Vite. للتحقق من النسخة الإنتاجية: `npm run build`. لتشغيل الاختبارات: `npm test`.

## ملاحظات حول البيانات

هذه النسخة تحفظ بياناتها محلياً في `localStorage` على المتصفح والجهاز الحالي، ولا تتضمن خادماً أو حسابات مستخدمين أو مزامنة سحابية أو تكاملاً مصرفياً لمعالجة البطاقات. سجلات الدفع والعمولات مؤشرات تشغيلية داخل التطبيق وليست نظام محاسبة أو رواتب أو فواتير ضريبية. نزّل نسخة احتياطية دورية قبل تغيير الجهاز أو المتصفح.

# مِقص — Barber App

تطبيق ويب عربي ومتجاوب لإدارة عمل الحلاق، مستوحى من الواجهة الداكنة والبرتقالية في المرجع.

## الميزات

- **لوحة التحكم:** مواعيد اليوم، الموعد القادم، ملخص الزبائن والإيرادات، وأداء الأسبوع.
- **المواعيد:** عرض يومي، بحث وتصنيف، إضافة وتعديل وحذف، تأكيد وإكمال وإلغاء، مع منع تداخل أوقات الحجوزات واقتراح أول وقت متاح.
- **الزبائن:** إضافة وتعديل وحذف، اتصال مباشر، ملاحظات وسجل زيارات.
- **الدفعات:** تسجيل الدفع نقداً أو بالبطاقة أو بالتحويل، عرض المستحقات والمدفوعات، وإلغاء تسجيل دفعة عند الحاجة.
- **التقارير:** ملخص الفترة، رسم الإيرادات، أكثر الخدمات طلباً، وتصدير CSV.
- **الإعدادات:** اسم الصالون، أسماء الخدمات وأسعارها ومددها، وتنزيل واستعادة نسخة احتياطية JSON.

واجهة RTL ملائمة للجوال والكمبيوتر، مع بيانات تجريبية تظهر عند التشغيل لأول مرة. تحفظ التعديلات تلقائياً في **localStorage** في المتصفح نفسه؛ لا توجد مزامنة سحابية أو حسابات مستخدمين أو خادم خلفي في هذه النسخة.

## التشغيل

```bash
npm install
npm run dev
```

ثم افتح العنوان الذي يعرضه Vite. للتحقق من النسخة الإنتاجية: `npm run build`. لتشغيل الاختبارات: `npm test`.
